# 这是什么项目？

一个用 Python Flask 写的**微信小程序商城后端**。

## 一句话定位

**mini-shop-server** 是给「微信小程序商城」提供数据接口的后端服务。

它不写页面，只负责：接收小程序的请求 → 校验、查数据库 → 把 JSON 数据返回。

```
📱 微信小程序（前端）→ ⚙️ mini-shop-server（本后端）→ 🗄️ PostgreSQL 数据库
```

## 技术栈

| 技术 | 在项目里干什么 |
|---|---|
| **Flask 2.0** | Python 的 Web 框架，接收 HTTP 请求 |
| **SQLAlchemy** | ORM，把「查数据库」写成 Python 对象操作 |
| **PostgreSQL** | 关系型数据库，真实存储数据 |
| **flasgger / Swagger** | 自动生成接口文档 |
| **WTForms** | 校验请求参数是否合法 |
| **uv** | Python 依赖安装 / 打包部署 |

## 核心思想

整个项目的主线是 **「分层 + AOP（面向切面）」**。

请求不是一步到底，而是像剥洋葱一样，依次穿过「认证壳、校验壳、业务层、数据层」，每一层只管一件事。理解这条主线，后面的章节读起来会更顺。

::: tip 交给你的第一件事
打开 `app/__init__.py`，这是全项目的总入口（工厂函数 `create_app()`），一行行读注释，你会看到项目是怎么组装起来的。
:::
