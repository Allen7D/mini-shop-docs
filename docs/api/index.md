# API 参考

这里是 mini-shop-server 的接口总览。项目的在线 Swagger 文档见 [线上 API 文档](http://47.114.33.143:9000/apidocs/)。

## 接口版本划分

同一个后端为两个前端服务，分两套接口：

| 版本 | 前缀 | 服务对象 | 说明 |
|---|---|---|---|
| `v1` | `/v1/` | 小程序用户（C 端） | 商品、订单、支付、主题 |
| `cms` | `/cms/` | 后台管理（B 端） | 用户管理、权限、文章、文件 |

两个版本的接口都在 `app/api/` 下，分别对应 `v1/` 和 `cms/` 目录。

## 统一响应格式

所有接口返回统一格式：

```json
{
  "error_code": 0,
  "msg": "成功",
  "data": { }
}
```

- `error_code === 0` 表示成功
- 非 0 为业务错误码（见 [统一异常与响应格式](/guide/response)）

## 认证方式

C 端和部分 B 端接口需要携带 Token（`Authorization: Bearer <token>`）。Token 通过登录接口获取，见「C 端接口」的令牌接口。

- [C 端接口 (v1)](/api/v1)
- [B 端接口 (cms)](/api/cms)
