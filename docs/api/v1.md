# C 端接口 (v1)

给小程序用户使用的接口，前缀 `/v1`。源码位于 `app/api/v1/`。

| 模块 | 红图名 | 说明 |
|---|---|---|
| [令牌 token](#token) | `v1-token` | 登录、换取 Token |
| [用户 user](#user) | `v1-user` | 用户信息、注册 |
| [配送信息 address](#address) | `v1-address` | 收货地址管理 |
| [轮播图 banner](#banner) | `v1-banner` | 首页轮播图 |
| [主题 theme](#theme) | `v1-theme` | 专题主题 |
| [类别 category](#category) | `v1-category` | 产品类别 |
| [产品 product](#product) | `v1-product` | 商品详情、列表 |
| [订单 order](#order) | `v1-order` | 下单、订单查询 |
| [支付 pay](#pay) | `v1-pay` | 微信支付 |

## token

**登录，签发 Token**

```
POST /v1/token
```

登录方式支持：账号密码（用户名/邮箱/手机）和微信小程序 code。请求体：

```json
{
  "account": "999@qq.com",
  "secret": "123456",
  "type": 100
}
```

`type` 为 `ClientTypeEnum`：100 用户名、101 邮箱、102 手机、200 微信小程序。

## user

**查询个人信息**

```
GET /v1/user  (需 Token)
```

## address

**查询 / 新增 / 编辑 / 删除收货地址**

```
GET    /v1/address        (需 Token)
POST   /v1/address        (需 Token)
PUT    /v1/address/<id>   (需 Token)
DELETE /v1/address/<id>   (需 Token)
```

## banner

**查询轮播图**

```
GET /v1/banner/<id>       (ids 多选支持 /v1/banner/ids/1,2,3)
```

## theme

**查询主题（专题）**

```
GET /v1/theme/<id>
```

## category

**查询所有类别 / 类别下商品**

```
GET /v1/category
GET /v1/category/<id>/products (示意)
```

## product

**查询商品详情 / 商品列表(分页)**

```
GET /v1/product/<id>
GET /v1/product/by_category?id=1
```

## order

**下单 / 订单列表 / 订单详情**

```
POST /v1/order            (需 Token)
GET  /v1/order?page=1&size=10   (需 Token)
GET  /v1/order/<id>       (需 Token)
```

## pay

**预支付 / 支付回调**

```
POST /v1/pay/pre_order    (需 Token)
POST /v1/pay/notify       (微信回调)
```
